 Family Tree in C

 Project Description

This project represents a three-generation family tree using the C programming language. It stores information about seven family members and uses pointers to connect each person to their father and mother.

 Features

- Stores each person's name and age.
- Uses a Person structure to represent family members.
- Uses pointers to link parents and children.
- Displays family relationships.
- Frees allocated memory when the program finishes.

 Requirements

- compiler such as GCC.
- Visual Studio Code or another code editor.

 How to Compile and Run

 Open a terminal in the project folder and run.
-gcc family_tree.c -o family_tree

On Windows, run the compiled program with:
.\family_tree.exe
